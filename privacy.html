개인정보처리방침 (Privacy Policy)

교회영상 업로드 · 시행일 2026-10-26

1. 이용 목적

"교회영상 업로드"는 영락교회 고등부 미디어팀이 고등부 유튜브 채널에 예배 영상을 업로드하기 위해 사용하는 내부용 프로그램입니다. Google 계정 인증(OAuth)을 통해 채널 소유자 본인의 유튜브 채널에 영상 업로드, 썸네일 설정, 재생목록 추가만 수행합니다.

2. 접근하는 정보

  • YouTube 채널 기본 정보(채널 이름, ID) — 업로드 대상 채널 확인용
  • YouTube 업로드 및 관리 권한 — 영상 업로드, 썸네일 설정, 재생목록 추가용

그 밖의 개인정보(연락처, 시청 기록, 다른 사용자의 정보 등)는 수집하거나 접근하지 않습니다.

3. 저장 및 공유

인증 토큰은 미디어팀이 사용하는 컴퓨터에만 저장되며, 외부 서버로 전송하거나 제3자와 공유·판매하지 않습니다. Google API를 통해 받은 정보는 위 목적 외에는 사용하지 않습니다.

4. Google API 서비스 사용자 데이터 정책 준수

이 프로그램이 Google API로부터 받은 정보의 사용 및 전송은 Google API Services User Data Policy의 제한적 사용(Limited Use) 요구사항을 포함한 정책을 준수합니다.

5. 권한 철회

언제든지 Google 계정 권한 관리에서 이 프로그램의 접근 권한을 철회할 수 있습니다.
